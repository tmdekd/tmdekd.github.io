retrospective:
  sections:
    - title: 팀장으로서의 역할 인식
      body: >-
        이번 VINO 프로젝트는 와인 입문자를 위한 챗봇을 직접 기획하고, 설계부터 구현까지 전 과정을 책임진 첫 팀장 경험이었다.
        AI·LLM을 함께 공부해 온 동료들이 아닌, 각자 강점과 속도가 다른 팀원들과 협업해야 했기 때문에 기술 구현보다도 의사결정의 맥락을 설명하고 방향을 공유하는 역할이 중요했다.
        단순히 "되는 코드"를 만드는 것이 아니라, 팀 전체가 구조를 이해하고 따라올 수 있도록 정리하는 과정에서 팀장이라는 자리의 무게를 실감했다.
    - title: 응답 구조의 재설계
      body: >-
        단순한 LLM 응답 생성에 그치지 않고, sLLM → GPT 기반 응답 평가 → RAG → 외부 검색(Tavily)으로 이어지는 다단계 응답 흐름을 설계했다.
        LLM의 응답을 그대로 신뢰하기보다, GPT 모델을 활용해 "이 응답이 충분한가?"를 평가 기준으로 삼고, 필요할 때만 검색 범위를 확장하는 구조를 코드로 구현했다.
        이 과정에서 생성과 평가를 분리한 구조가 hallucination을 줄이고, 사용자에게는 하나의 정제된 답변만 제공할 수 있다는 점이 특히 인상 깊었다.
    - title: 선택과 집중의 경험
      body: >-
        제한된 개발 기간과 인프라 환경 속에서, 모든 기능을 완성하기보다 핵심 파이프라인의 안정성에 집중했다.
        AWS 배포 과정에서 디스크 용량 이슈로 완전한 CI/CD 구성까지는 도달하지 못했지만, 파인튜닝된 모델을 직접 업로드하는 대안적 접근을 검토하며 현실적인 문제 해결 방식을 고민했다.
        또한 Django Admin 권한 이슈를 해결하며, 단순한 버그 수정이 아닌 프레임워크 구조를 이해하는 경험을 쌓을 수 있었다.
